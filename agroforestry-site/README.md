# Emertech — Agroforestry dMRV Landing Page

React + Vite. Inline styles (no Tailwind build), fonts via Google Fonts.

## Dev
    npm install
    npm run dev

## Build
    npm run build
    npm run preview

## Deploy
Push this folder to a GitHub repo, then import the repo on vercel.com —
it auto-detects Vite (build command `npm run build`, output directory `dist`).
No other configuration needed.
